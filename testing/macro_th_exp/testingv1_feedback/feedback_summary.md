How institutional funds approach HMM training — walk-forward validation, and what you must run now:
Bridgewater, AQR, and comparable macro funds do not use a single 25/10 train/test split. They use walk-forward validation — an expanding window where every test year is genuinely unseen by the model that predicted it. Before you can run any of this, you need to understand what the model is actually learning and what parameters it is estimating. Read this section fully before writing a single line of code.

What the HMM learns from training data — the three parameter sets:
When you call hmmlearn's GaussianHMM.fit() on your historical weekly percentile vectors, it estimates three things simultaneously using the Baum-Welch algorithm (a special case of Expectation-Maximisation):
Parameter set 1 — the initial state distribution (3 parameters, 2 free). The probability of being in each state at the very start of the sequence. A vector like [Risk-On: 0.70, Risk-Off: 0.15, Transition: 0.15]. One parameter is determined by the others summing to 1, so 2 free parameters. This matters less than the other two sets — it only affects the first observation.
Parameter set 2 — the transition probability matrix (9 entries, 6 free parameters). A 3×3 matrix where entry (i,j) is the probability of moving from state i to state j in one week:
                 To Risk-On    To Risk-Off   To Transition
From Risk-On    [   p11             p12            p13     ]
From Risk-Off   [   p21             p22            p23     ]
From Transition [   p31             p32            p33     ]
Each row must sum to 1 — you must be somewhere next week including staying in the same state. That constraint means each row has only 2 free parameters, giving 3 rows × 2 free parameters = 6 free parameters total.
What the learned values will look like economically, and why each matters:
p11 (stay Risk-On | currently Risk-On): typically 0.92–0.97. Bull markets are persistent — regimes do not flip weekly. A high p11 means once Risk-On fires you expect it to persist for months.
p22 (stay Risk-Off | currently Risk-Off): typically 0.85–0.92. Risk-Off regimes are shorter and more violent than Risk-On. Lower than p11 reflecting that bear markets resolve faster than bull markets build.
p33 (stay Transition | currently Transition): typically 0.70–0.85. Transition is inherently unstable — it resolves either toward Risk-On or Risk-Off. Lower persistence than either terminal state.
p12 (Risk-On → Risk-Off directly): typically very small, 0.01–0.03. Markets almost never go from full bull to full bear in a single week. If this value is high after training something is wrong with your state labelling.
p13 (Risk-On → Transition): typically 0.03–0.08. The normal path is Risk-On → Transition first, then either back to Risk-On or forward to Risk-Off. This is the early warning channel.
p21 (Risk-Off → Risk-On directly): small but larger than p12, maybe 0.05–0.10. Capitulation bottoms can reverse sharply — March 2020 is an example of a fast Risk-Off → Risk-On transition.
p23 (Risk-Off → Transition): typically 0.08–0.15. Risk-Off can move back through Transition before settling into Risk-On.
p31 and p32 (Transition → Risk-On or Risk-Off): these two together determine whether a warning period resolves bullishly or bearishly. If p31 > p32 historically, most Transition periods resolved back to Risk-On — soft landings were more common than crashes. If p32 > p31, most Transition periods preceded genuine Risk-Off.
Why the transition matrix is valuable beyond the posterior probabilities: it tells you the typical path through regimes and the expected duration in each state. The expected number of weeks in Risk-On before leaving = 1/(1 − p11). If p11 = 0.95, expected duration = 1/0.05 = 20 weeks. For Risk-Off with p22 = 0.88, expected duration = 1/0.12 = 8.3 weeks. These durations should correlate with your named combo horizons — Combo F's 26-week window and Combo B's 3-month recovery horizon should be consistent with the learned transition matrix. If they are not, either the combo horizons or the HMM state definitions need revisiting.
This also connects directly to Combo G. If p13 is meaningfully larger than p12 (Risk-On almost always transitions via Transition before reaching Risk-Off), then periods of high Transition posterior probability are early warnings — exactly what Combo G is designed to detect. You can validate Combo G's historical lead time by checking whether it fires during high-p13 Transition periods. If Combo G fires consistently when the HMM is in Transition state, that is independent validation that G is detecting the genuine pre-stress regime.
Parameter set 3 — the emission distributions (the largest set). For each state, a multivariate Gaussian distribution over the 14-variable percentile vector. Each Gaussian has a mean vector (14 parameters — one per variable) and a covariance matrix. With full covariance: 14×15/2 = 105 parameters per state. With diagonal covariance (assuming conditional independence between variables within each state): 14 parameters per state. Total parameters:
Full covariance: 3 states × (14 + 105) = 357 emission parameters
Diagonal covariance: 3 states × (14 + 14) = 84 emission parameters
Use diagonal covariance for version 1. Against roughly 1,300 weekly observations (1990–2014 training window), full covariance requires estimating 357 parameters — approximately 3.6 observations per parameter, below the 10× minimum rule of thumb for stable estimation. Diagonal covariance requires only 84 parameters — approximately 15 observations per parameter, comfortably stable. The diagonal assumption means you treat each variable as conditionally independent within each state. This is an approximation — VIX and HY are clearly correlated — but it is a stable one for a first version. You can test full covariance once you have more data.
What the learned emission means will look like:
Risk-On mean vector: [VIX: ~0.28, HY: ~0.31, CFTC: ~0.78, NFCI: ~0.25, WTI: ~0.45, CAPE: ~0.72...] Risk-Off mean vector: [VIX: ~0.85, HY: ~0.82, CFTC: ~0.12, NFCI: ~0.74, WTI: ~0.65, CAPE: ~0.55...] Transition mean vector: somewhere between the two — elevated stress readings but not at extremes
Note that VIX and HY are HIGH in Risk-Off while CFTC is LOW — different variables move in opposite directions in each regime. The Gaussian captures this joint pattern including the opposing movements. When a new week's vector arrives, the code computes P(this vector | Risk-Off Gaussian) and P(this vector | Risk-On Gaussian) and updates the posterior accordingly. History is encoded in those learned Gaussians — the model does not re-scan 35 years every week. The forward-backward algorithm in hmmlearn handles the posterior computation automatically.

4. TRANSITION PROBABILITY — THE OPTIONS FRAMEWORK
This is important enough that I want you to understand it conceptually, not just implement it.
Every combo has a cancel condition. Instead of saying qualitatively "the WTI leg may be clearing," we compute the probability of cancellation rigorously using options pricing logic. The cancel condition is treated as a digital barrier option:
The underlying = WTI price (or whatever variable is relevant)
The strike = the threshold that, if breached, contributes to cancellation (e.g. WTI price 4 weeks ago × 1.05)
Time to expiry = number of remaining Fridays required
Vol = annualised volatility of the underlying
Per-Friday cancel probability = N(−d2) from Black-Scholes, where d2 = [ln(S/K) + (−σ²/2)T] / (σ√T). This is the risk-neutral probability that WTI on that Friday will be below the strike.
The consecutive requirement (4 Fridays in a row) makes this path-dependent — like an Asian digital option. Because consecutive 4-week windows overlap by 3 of 4 weeks, the readings are correlated (ρ ≈ 0.75). You cannot multiply four independent probabilities. Use Monte Carlo with GBM paths over the 4 weeks — this captures the correlation structure exactly.
The output is: P(Combo C WTI leg cancels in next 4 weeks) = a single number between 0 and 1. Multiply by P(CPI non-hot for 2 consecutive prints) to get total cancel probability. Display this live on the nightly briefing and dashboard for every active combo.
